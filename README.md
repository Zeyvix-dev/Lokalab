# Lokalab

Veřejná stránka pro nezávislé lokalizační projekty. Aktuálně zde najdeš pouze český překlad **WinTrack 17.0**.

## Publikace přes GitHub Pages

1. Otevři **Settings → Pages** v tomto repozitáři.
2. V části **Build and deployment** vyber **Deploy from a branch**.
3. Jako branch zvol **main**, složku **/(root)** a stiskni **Save**.
4. Po dokončení nasazení bude web dostupný na adrese: https://zeyvix-dev.github.io/Lokalab/
